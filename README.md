## 🚀 ¿Qué hace?

- 📥 **Instala Office automáticamente** (16 versiones disponibles)
- ⚡ **Activa Office** (método Ohook permanente)
- 🪟 **Activa Windows** (licencia digital HWID)
- 🔧 **Repara Office** dañado
- 🗑️ **Desinstala Office** completamente
- 🔍 **Verifica estado** de activación
- 📊 **Muestra información** del sistema

---

## 🎯 ¿Para quién es?

Para **cualquier persona** que necesite Microsoft Office y no quiera complicarse con instalaciones técnicas. Ideal para:

- 🎓 **Estudiantes** que necesitan Office para sus clases
- 👩‍🏫 **Profesores** que gestionan múltiples equipos
- 💻 **Cualquier usuario** de Windows
